Core principle

QA shouldn't happen only at the end. A dashboard moves through QA in stages so issues get caught early and not right before client delivery.

A few things worth watching for

Small build details that cause a lot of the rework later on.

Chart type should match the data. A pie chart doesn't work for something that changes over time as that needs a line or bar chart instead. Picking the wrong chart type for the data is one of the easiest things to miss and one of the most visible things a client will notice.
Date columns need their own look. Fiscal periods, YTD, rolling periods are easy to get subtly wrong. Once a date column is built, get QA to check it on its own before building more on top of it.
